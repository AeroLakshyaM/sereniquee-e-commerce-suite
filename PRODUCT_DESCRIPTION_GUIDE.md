# Product Full Description Guide

## Overview

The Sereniquee e-commerce suite now includes a comprehensive **Full Product Description** system that allows you to add detailed, professional product descriptions with technical specifications, scent profiles, care instructions, and more.

## Features

✅ **Database Storage** - All full descriptions are stored in the `full_description` column in the products table
✅ **Admin Dashboard Integration** - Easy-to-use textarea editor in the product management form
✅ **Markdown-like Formatting** - Support for bold text, bullet points, and paragraphs
✅ **Automatic Display** - Full descriptions appear in an accordion on product detail pages
✅ **Fallback Content** - Shows default description if full description is not provided

## How to Use in Admin Dashboard

### Adding/Editing Product Descriptions

1. **Navigate to Admin Dashboard** → Products Tab
2. **Click "Add Product"** or **Edit** an existing product
3. **Scroll to "Full Product Description"** textarea
4. **Paste or type your detailed product description**
5. **Use formatting syntax** (see below)
6. **Click "Save"**

### Formatting Syntax

The full description field supports simple markdown-like formatting:

#### Bold Text
```
**Your text here**
```
Example: `**Technical Specifications**` → **Technical Specifications**

#### Bullet Points
```
* Item one
* Item two
* Item three
```
Or use hyphens:
```
- Item one
- Item two
- Item three
```

#### Paragraphs
Simply leave blank lines between paragraphs:
```
This is paragraph one.

This is paragraph two.
```

## How to Customize for Each Candle

### 1. Technical Specifications

**Net Weight:**
- Use a kitchen scale to weigh your filled candle
- Convert to both grams and ounces for international customers
- Example: 200g / 7 oz

**Dimensions:**
- Measure height from base to top of jar (without lid)
- Measure diameter across the top opening
- Use centimeters and/or inches
- Example: 8.5 cm (Height) x 7 cm (Diameter)

**Burn Time:**
- General rule: 5-7 hours per ounce for soy wax
- For a 7 oz (200g) candle: ~35-49 hours
- You can safely estimate "40-45 hours" or "40+ hours"
- Test burn a sample to verify

**Vessel Material:**
- Glass: "High-grade heat-resistant glass"
- Ceramic: "Handcrafted ceramic"
- Metal: "Vintage-style metal tin"

### 2. Scent Profile

If you don't know the exact fragrance breakdown:

**Option A - Simple Format:**
```
**Fragrance Notes**

A warm blend of Vanilla, Caramel, and Honey with subtle hints of Cinnamon
```

**Option B - Top/Heart/Base Structure:**
```
**Scent Profile**

* Top Notes: Citrus, Bergamot (what you smell first)
* Heart Notes: Lavender, Rose (the main scent)
* Base Notes: Sandalwood, Musk (lingering scent)
```

**Common Scent Categories:**
- **Top Notes:** Citrus, Mint, Herbs, Light Florals
- **Heart Notes:** Rose, Jasmine, Lavender, Spices
- **Base Notes:** Vanilla, Sandalwood, Musk, Amber

### 3. Candle Care Tips

You can customize the care instructions, but always include:
- Wick trimming (1/4 inch)
- First burn instructions (prevent tunneling)
- Safety warnings (never leave unattended)

## Technical Details

### Database Structure
- **Field:** `full_description`
- **Type:** `TEXT`
- **Nullable:** Yes
- **Location:** `products` table

### Frontend Display
- **Location:** Product detail page → "Full Description" accordion
- **Formatting:** Automatic parsing of markdown-like syntax
- **Fallback:** Shows generic description if full_description is null

### Admin Interface
- **Location:** Product form → "Full Product Description" field
- **Type:** Large textarea (15 rows)
- **Features:** Auto-save on submit, character count, formatting hints

## Troubleshooting

**Q: Formatting isn't working?**
- Ensure you're using `**text**` for bold (two asterisks, not one)
- Make sure bullet points start with `*` or `-` followed by a space
- Leave blank lines between paragraphs

**Q: Description too long?**
- No character limit, but aim for 500-1500 words
- Break into sections with headings
- Use bullet points for readability

**Q: Changes not showing?**
- Hard refresh the page (Ctrl+F5 or Cmd+Shift+R)
- Check if product was saved successfully
- Verify database migration was applied
